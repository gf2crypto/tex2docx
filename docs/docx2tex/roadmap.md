# docx2tex — дорожная карта

Обратный инструмент: часть отчета, написанная в Word, становится фрагментом LaTeX и
встраивается в существующий документ одной командой `\input{}`. Исполняемая часть дорожной
карты — `xfail_*` в `tests/docx2tex/corpus/*/expect.yaml` и в `tests/roundtrip/`.

## Требования (от заказчика, 2026-10-31)

1. **Офлайн.** Ни один этап не обращается к сети. Инструменты те же, что у tex2docx:
   pandoc, TeX Live, poppler, Python; ничего нового ставить не нужно.
2. **Минимум нового в LaTeX.** На выходе — обычный LaTeX: `article`/`amsmath`/`amsthm`/
   `graphicx`/`booktabs`, окружения `theorem`/`equation`/`align`/`figure`/`table`/
   `itemize`/`enumerate`. Никаких своих пакетов и макросов; все, что нужно подключить,
   перечислено в отчете и в `\input`-фрагменте не дублируется, если уже есть в основном документе.
3. **Устойчивость круга.** `tex → docx → tex → docx → …` над одним документом не накапливает
   мусора: номера и ссылки не меняются, текст не обрастает пробелами, пустыми абзацами
   и лишними `{}`; результат второго круга совпадает с первым (это тест, см. ниже).

Основной сценарий: отчет пишется в LaTeX, соавтор приносит свою главу в Word (набирал сам
или правил docx, полученный от tex2docx). Нужно с минимальными усилиями получить
`chapter.tex`, который `\input` в отчет, и чтобы он собрался с первого раза.

## M0 — каркас (готово)

- [x] Пакет `src/docx2tex/`, CLI `docx2tex chapter.docx [-o chapter.tex] [--standalone]`,
      тот же конвейер этапов над `Context`, тот же отчет без текста документа
      (`chapter.report.md`), общие с tex2docx `report.py`, `tools.py` и правила `CLAUDE.md`.
- [x] Этап `extract`: закладки и поля из `word/document.xml` (pandoc их теряет), документ-спутник
      `<имя>.t2d.xml` (ADR 0008), язык (спутник → конфиг → по тексту).
- [x] Этап `pandoc`: `pandoc -f docx+styles -t latex --extract-media` с фильтром `structures.lua`
      (заголовки без `\hypertarget` и номеров, абзац из одной формулы — выносная, списки без
      обертки стилей, простые таблицы — `tabular`); формулы OMML → LaTeX средствами texmath.
- [x] Этап `normalize`: `\(…\)` → `$…$`, мусор pandoc, пути картинок, `~`; идемпотентен.
- [x] Этап `emit`: фрагмент без преамбулы, нужные пакеты — `emit.package` в отчете, картинки в
      `images/`; `--standalone` пишет документ с преамбулой, `check` собирает его `latexmk`.
- [x] Корпус `tests/docx2tex/corpus/` (docx строятся `make.py`), кейс `word-basic` зеленый;
      тест круга `tests/roundtrip/` работает и ожидаемо падает до M1.
- [ ] Документ-спутник внутри docx (`docProps/custom.xml`), чтобы переживал переименование файла.

## M1 — структуры tex2docx узнаются обратно (готово)

Что tex2docx кладет в docx, docx2tex читает без потерь (это «контракт круга»,
`docs/docx2tex/roundtrip-contract.md`; тест — `tests/roundtrip/`, все шесть кейсов зеленые
на pandoc 3.1.3 и 3.12.1):

- [x] этап `prepare` (`stages/prepare.py`): рабочая копия docx для pandoc — закладки, поля REF/SEQ
      и табуляторы записаны в текст маркерами из области частного использования Unicode
      (pandoc их иначе теряет); фильтр `structures.lua` их снимает;
- [x] стили `Theorem`/`Definition`/`Remark`/`Proof` → окружения amsthm; имя окружения —
      по слову заголовка (словарь `theorem_envs` конфига, объявления из спутника);
      номер отбрасывается, «(Заметка)» → необязательный аргумент, курсив тела снимается;
      формулы, попавшие в закладку теоремы, остаются внутри окружения;
- [x] абзац стиля `Equation` → `equation`/`\[ \]`; строки с `&` подряд → `align` (`\notag`
      для строк без номера), «(2.5a)» → `subequations`, несколько строк под одним номером →
      `aligned`/`multline`, `\tag`/`\tag*`; `\label` — из закладки `t2d_<метка>` (теперь tex2docx
      ставит ее и без живых номеров);
- [x] ссылки: поля `REF` и гиперссылки на закладки → `\ref`, «(N)» → `\eqref`;
- [x] заголовки → `\section`…`\subparagraph`, номер «1 Введение» отбрасывается, `\label` из закладки;
      заголовок без номера среди нумерованных → `\section*`;
- [x] `Image Caption`/`Table Caption` (и `Caption` Word) → `figure`/`table` с `\caption`/`\label`;
- [x] `Algorithm Caption` + абзацы `Algorithm` → `algorithm`/`algorithmic` (ключевые слова →
      `\If`/`\For`/`\Function`/…; блоки без строк `end` закрываются по отступу табуляторами);
- [x] библиография: заголовок «Список литературы» + нумерованный список (или абзацы
      `Bibliography`) → `thebibliography`; «[1, 2]» → `\cite` с ключами из спутника (`<cites>`),
      иначе `bib:N`;
- [x] `Centered`/`Right Aligned`/`Left Aligned` → `center`/`flushright`/`flushleft`; `Abstract` →
      `abstract`; заголовок документа (стили `Title`/`Author`) → `\maketitle` с закомментированными
      `\title`/`\author` (основной документ объявляет свои).
- [ ] Текстовые «(2.1)» без поля (соавтор набрал номер руками) остаются текстом; отчет
      `refs.plain-number` — M2.

## M2 — документ, набранный в Word руками

- [ ] Прямое форматирование вместо стилей: полужирный/курсив → `\textbf`/`\emph`;
      абзац, начинающийся с «Теорема 3.» полужирным, → `theorem` (эвристика, в отчете);
      центрированный абзац из одной формулы → выносная формула.
- [ ] Формулы Word в «линейном» виде, формулы-картинки, формулы MathType (OLE) → отчет
      `math.not-omml`, картинка переносится как есть.
- [ ] Таблицы: объединенные ячейки → `\multicolumn`/`\multirow`, рамки → `booktabs`
      или `|`, ширина — `p{}` по ширине столбца.
- [ ] Списки Word (нумерация через `numbering.xml`) → `enumerate`/`itemize` с вложенностью.
- [ ] Сноски, перекрестные ссылки Word (`REF _Ref…`, подписи `SEQ Рисунок`) → `\label`/`\ref`.
- [ ] Картинки EMF/WMF → PDF через LibreOffice, если есть; иначе отчет.
- [ ] Макросы основного документа: конфиг `macros:` в обратную сторону
      (`\mathbf{G}` → `\matr{G}` там, где это буквенная замена) — чтобы фрагмент выглядел
      как написанный автором.

## M3 — круг и интеграция

- [x] Тест круга: для каждого кейса корпуса tex2docx `tex → docx → tex → docx`, второй docx
      совпадает с первым по зонду (текст, число формул, стили, поля) и `tex → docx → tex`
      дает фрагмент, который компилируется и дает те же номера в `.aux` (M1).
- [x] Стабильность текста: третий круг ничего не меняет (idempotent) — тот же тест.
- [ ] `--into main.tex`: фрагмент пишется рядом с основным документом, в отчет — какие
      пакеты и `\newtheorem` в его преамбуле отсутствуют (сравнение с `collect_decls`).
- [ ] Библиография по тексту записей: сопоставление абзацев `Bibliography` с `.bib`
      основного документа → `\cite{key}` с настоящими ключами.
- [ ] Windows: та же переносимая папка, `docx2tex.bat`.

## Сознательно не делаем

- Восстановление исходного `.tex` символ в символ после Word: цель — корректный и
  аккуратный LaTeX, а не прежний текст.
- Оформление (шрифты, размеры, цвета, отступы) из docx не переносится: его задает
  преамбула основного документа.
- Формулы, которых нет в OMML (картинки, MathType), не распознаются.
