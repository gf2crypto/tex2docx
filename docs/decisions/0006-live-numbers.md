# ADR 0006. Живые номера — поля SEQ/REF, по желанию

Статус: принято (2026-10-27).

## Контекст

Номера из `.aux` — текст: совпадают с PDF, но после правок в Word не пересчитываются.
Редактору журнала нужны и точные номера, и возможность вставить теорему без ручной перенумерации.

## Решение

Ключ `live_numbers` (по умолчанию `false`). Когда включен, каждый номер простого вида
(«N», «N.N», «N.N.N») становится полем Word внутри закладки `t2d_<метка>`:

- раздел уровня 1 — `SEQ h1`; глубже — `REF <родитель>.SEQ hN \s N-1`;
- формула/теорема/рисунок с номером «2.1» по разделам — `REF <раздел>.SEQ <счетчик> \s <уровень раздела>`,
  без разделов — `SEQ <счетчик>`; общий счетчик теорем/лемм — одно имя SEQ;
- `\ref`/`\eqref` — `REF <закладка> \h` (ссылка остается кликабельной).

Текст поля — номер из LaTeX, поэтому до обновления полей документ выглядит ровно как PDF,
после (Ctrl+A, F9) — как пересчитал Word. `\tag`, подформулы «2.3a», `\cref` с текстом,
подписи с нестандартными номерами остаются текстом.

Фильтры помечают номера Span-маркерами (`t2d.number`, `t2d.ref`), а последний фильтр
`numbers.lua` превращает их в текст или поля, идя по документу по порядку (знает ближайший
заголовок для префикса). Номера разделов в docx ставит `headings.lua` (pandoc их не нумерует),
метки разделам дает `autolabel`.

## Альтернативы

- `STYLEREF` для префикса раздела: требует нумерации заголовков списком в стилях Word;
  в LibreOffice и без нумерованных стилей подставляет текст заголовка. Отвергнуто.
- Нумерованные списки Word для заголовков: меняет шаблон стилей и не дает ровных номеров LaTeX до обновления.

## Последствия

- LibreOffice не понимает `\s` у SEQ (сквозная нумерация после пересчета); Word — понимает.
- Вставка/удаление раздела пересчитывает и формулы, и ссылки на них, в т.ч. в тексте «см. (2.1)».
