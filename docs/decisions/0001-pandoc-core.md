# ADR 0001. Ядро — pandoc, а не свой парсер

Статус: принято (2026-10-27).

## Контекст

Нужно получить docx с нативными формулами Word и теоремами как стилями из произвольной
математической статьи на LaTeX, без ручной работы.

## Решение

Ядро конвертации — pandoc (LaTeX reader + docx writer, формулы через texmath → OMML).
Свое — только тонкие слои вокруг: препроцессор TeX, Lua-фильтры над AST, постобработка docx.

## Альтернативы

- Свой парсер TeX → нет: TeX нельзя разобрать без выполнения, это бесконечная работа.
- make4ht (tex4ht) → ODT → LibreOffice → docx: выполняет настоящий TeX, поэтому макросы
  работают всегда, но контроль над стилями Word хуже, а формулы проходят два перевода
  (MathML → формулы LibreOffice → OMML). Оставляем как возможный запасной путь для
  «неразбираемых» документов.

## Последствия

- Мы зависим от того, что понимает pandoc; известные расхождения — в `docs/pandoc-behavior.md`.
- Все, что требует семантики TeX, берем у настоящего LaTeX (ADR 0002, 0003).
