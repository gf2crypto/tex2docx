# ADR 0003. Рисунки — картинками через пакет preview

Статус: принято (2026-10-27).

## Контекст

TikZ, pgfplots и прочую графику в объекты Word не перевести. Компилировать каждый рисунок
отдельно через `standalone` ненадежно: рисунку нужна преамбула документа (макросы, библиотеки
TikZ, стили).

## Решение

Копия `ctx.latex_tex` с `\usepackage[active,tightpage]{preview}` и `\PreviewEnvironment{env}`
для каждого окружения из `config.figure_envs` перед `\begin{document}` компилируется целиком;
каждая страница PDF — один рисунок в порядке исходника. `pdftoppm` → PNG (`figure_dpi`).
i-е окружение в `ctx.tex` заменяется на `\includegraphics{figures/fig-i.png}`.

## Последствия

- Работает для любой графики, которую умеет TeX, с родной преамбулой.
- Если число страниц не совпало с числом найденных окружений — ничего не подставляется,
  ошибка в отчете (неверная картинка хуже отсутствующей).
- Тот же механизм пригоден как запасной путь для формул, которые не переводит texmath (M2).
