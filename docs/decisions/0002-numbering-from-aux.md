# ADR 0002. Номера берем из .aux, а не вычисляем

Статус: принято (2026-10-27).

## Контекст

pandoc нумерует теоремы сам и ошибается (игнорирует `[section]`, `\numberwithin`, общие
счетчики классов), а формулы не нумерует вовсе. Эмулировать счетчики LaTeX для произвольного
класса невозможно.

## Решение

Компилируем документ настоящим LaTeX (latexmk) и читаем `\newlabel` из `.aux`.
Чтобы номер был у каждого объекта, этап `autolabel` (M1) вставляет метки `t2d:auto:N` туда,
где автор их не поставил, одинаково в `ctx.latex_tex` и `ctx.tex`.

## Последствия

- Нужен работающий TeX у пользователя; документ должен компилироваться.
- Если компиляция не удалась, конвертация продолжается с номерами pandoc, отчет предупреждает.
- Номера в docx совпадают с PDF автора символ в символ, включая `\textup{(i)}` и т.п.
