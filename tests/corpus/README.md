# Тестовый корпус

Каждая папка — один кейс: `main.tex` (+ любые `.sty`, картинки) и `expect.yaml`.
`tests/test_corpus.py` находит все кейсы сам.

**Только синтетика.** Реальных статей здесь нет и быть не должно. Если проблема пришла из
отчета по реальной статье — воспроизведи ее минимальным выдуманным примером.

Формат `expect.yaml` описан комментарием в `basic/expect.yaml`. Кратко:

- `contains` / `not_contains` — строки в тексте docx без формул (U+00A0 сравнивается как пробел);
- `math_min`, `images_min`, `styles` — количественные и стилевые проверки;
- `report_absent` — коды, которых не должно быть в отчете;
- `template` — требования к стилям docx (`font`, `size_pt`, `line_spacing`, `space_after_pt`,
  `heading_color`) для проверки профилей шаблона;
- `fields_min`, `fields_contain` — поля Word (`w:fldSimple`, по `w:instr`): живые номера;
- `report_where` — код → `файл:строка` (относительно main.tex), где он должен быть отмечен;
- `config.yaml` в кейсе — конфигурация конвертации (например, `engine: xelatex`);
- папка `texmf/` в кейсе — имитация личного texmf пользователя (подставляется в `TEXMFHOME`);
- `xfail_contains`, `xfail_report_absent` — запланированное; пока не сделано, тест ожидаемо падает.
