# Макросы пакетов дистрибутива для pandoc

pandoc не читает пакеты TeX Live, поэтому команды вроде `\xor` из cryptocode уходят
в texmath неизвестными. Файл `<пакет>.tex` подставляется в текст для pandoc сразу после
`\usepackage{<пакет>}` (этап `macros`): одна строка `\providecommand`, только математические
обозначения, которые texmath умеет. LaTeX эти файлы не видит.
