Иван прислал отчет конвертации реальной статьи: $ARGUMENTS
(если путь не указан — отчет вставлен в сообщение выше).

Самой статьи у нас нет и не будет. Работай только с отчетом.

1. Прочитай `docs/pandoc-behavior.md` и `docs/limitations.md`.
2. Сгруппируй строки отчета по причине (не по коду): одна причина может давать
   много `pandoc.skipped` и `pandoc.math-as-text`.
3. Для каждой группы реши и запиши в таблицу:
   - **исправить** — какой этап/фильтр, минимальный выдуманный пример для корпуса;
   - **уже в дорожной карте** — какой пункт `ROADMAP.md`;
   - **не поддерживаем** — причина (пойдет в `docs/limitations.md`);
   - **нужна информация** — что спросить у Ивана (например, как определен макрос),
     не прося текст статьи.
4. Покажи таблицу Ивану и дождись согласия, прежде чем править код.
5. По согласованным пунктам: кейс корпуса → тест падает → исправление → тест проходит →
   обновить `ROADMAP.md`, `docs/pandoc-behavior.md` или `docs/limitations.md`.
